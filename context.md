# PosiX — Contexto & Log do Projeto

## 🖥️ Resumo do Projeto
Gerenciador e restaurador de posições e dimensões de janelas para Linux (Zorin OS / GNOME). Construído em Python 3.12 com interface em GTK 4 e Libadwaita, integrado diretamente ao compositor Mutter via extensão GNOME Shell (GJS) e D-Bus. Permite salvar layouts de janelas, identificar aplicações mesmo entre reinicializações através de algoritmo de matching e restaurar geometrias com precisão pixel a pixel em múltiplos monitores.
